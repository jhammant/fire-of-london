# Fire Of London

A turn-based strategy game you play in a browser. It is September 1666 and a
bakery in Pudding Lane is alight. Learn what really happened in the Great Fire
of London while you try to stop it.

No build step and no dependencies: plain ES modules served as static files.

```bash
npm start   # then open http://localhost:8080
npm test    # Node's built-in test runner
```
